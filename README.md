# typeburst

ブラウザで遊べる、演出が派手で爽快感のあるタイピングゲームです。
画面は暗い背景と等幅フォントだけの静かな見た目ですが、打つたびに光・音・粒子がはじけます。

**▶ 遊ぶ：https://konja9.github.io/typeburst/**

PC のキーボードでも、スマホのソフトウェアキーボードでも遊べます。インストールや登録はいりません。

## 遊び方

1. 画面を開いて文字を打つとスタート（スマホは画面をタップしてキーボードを出す）
2. 30秒または60秒のあいだに、表示された単語をできるだけ速く正確に打つ
3. 時間が来ると結果画面でスコア・WPM・正確率などが出る

| キー | 動作 |
|---|---|
| `Space` | 次の単語へ（ローマ字モードは自動で次へ進むので不要） |
| `Backspace` | 1文字戻る |
| `Tab` | やり直し |
| `Enter` | 結果画面からもう一度 |
| `Esc` | 記録・遊び方の画面を閉じる |

ゲームの細かいルールは、画面右上の「?」から開ける遊び方の画面にもまとめています。

## 出題モード

| モード | 内容 |
|---|---|
| 英単語 | ランダムな英単語 |
| 英文 | 短い英文（小文字・句読点なし）を単語ごとに打つ |
| ローマ字 | 日本語の短い文を文節ごとにローマ字で打つ。`shi`／`si`、`tsu`／`tu`、`ん` の `nn` など、好きな綴りで打てる |

英文・日本語の文章はどちらも200本ずつ、このゲームのために書いたものです。

## 難易度

| 難易度 | ミスしたとき | スコア |
|---|---|---|
| ノーマル | コンボが途切れ、ゲージが減る | ×1 |
| ☠ ハード | コンボ・フィーバー・ゲージ・コード進行がすべて最初に戻る | ×1.5 |
| ☠☠ ハードコア | その時点でゲーム終了 | ×2 |

## 盛り上がりのしくみ

- **コンボ**：正しく打ち続けると、20・50・100・200 で色が変わり、倍率が ×1〜×5 に上がる
- **フィーバー**：正しく打つとゲージが貯まり、満タンでフィーバーに入る。fever → super fever → hyper fever → ultra fever → LIMIT BREAK の5段階（倍率 ×2〜×6）。フィーバー中はゲージが減り続け、0になると1段階下がる
- **音楽**：1打ごとにコード進行（Am→F→C→G）に沿った音が鳴り、段階が上がるほど BPM とパートが増える
- **CRITICAL**：ときどき金色の単語が出る。打ち切るとその単語の得点が ×3
- **自己ベスト**：プレイ中に自己ベストまでの差が表示され、超えた瞬間に NEW RECORD

### スコアの計算

- 1打：10点 × 倍率
- 単語を打ち切る：（文字数×25 ＋ 連続正解数×5）× 倍率
- 倍率：コンボ × フィーバー × 難易度

## 設定

画面上部のヘッダーで切り替えます。設定はブラウザに保存されます。

- 出題モード、時間（30秒／60秒）、難易度
- 音のオン／オフ（音符アイコン）
- 演出の強さ（弱・中・強の3段階）。OS の設定で動きを減らしている場合（`prefers-reduced-motion`）は、最初から弱になる
- テーマ（10種類）：ナイト、モノクロ、ペーパー、クリーム、オーシャン、フォレスト、トワイライト、サクラ、エンバー、サイバー

## 記録

- 結果は出題モード × 難易度 × 時間の区分ごとに、上位10件と直近20件をブラウザ（localStorage）に保存します
- 記録画面では、区分ごとの自己ベスト、ランキング、最近のプレイを見られます
- 結果や自己ベストは、テキストでコピー・X に投稿・端末の共有機能で共有できます
- 記録はそのブラウザの中にだけ保存されます。別の端末やブラウザとは共有されず、ブラウザのデータを消すと記録も消えます

## 技術的なこと

- HTML・CSS・JavaScript だけで作っていて、ビルドは不要です。ゲームの本体は `index.html` の1ファイルです
- 効果音と音楽は音声ファイルを使わず、Web Audio API でその場で合成しています
- 外部のスクリプトは使っていません（フォントの JetBrains Mono だけ Google Fonts から読み込みます）

### ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | ゲーム本体（見た目・動き・音・出題データをすべて含む） |
| `favicon.svg`、`favicon-32.png`、`icon-180.png` | ブラウザのタブとスマホのホーム画面用のアイコン |
| `CLAUDE.md` | 開発方針と、今の仕様のまとめ |

### 手元で動かす

リポジトリを取得して `index.html` をブラウザで開けば、そのまま遊べます。

```sh
git clone https://github.com/konja9/typeburst.git
cd typeburst
open index.html      # Windows は start index.html、Linux は xdg-open index.html
```

アイコンやシェアの URL まで本番と同じ状態で確かめたい場合は、簡易サーバーを立てて開きます。

```sh
python3 -m http.server 8000   # http://localhost:8000/ を開く
```

### 公開

GitHub Pages で `main` ブランチの直下を公開しています（Settings → Pages → Deploy from a branch → `main` / `(root)`）。`main` を更新すると、1〜2分で公開ページに反映されます。
